# Contributors

Thank you to everyone who has contributed to Nixite! This project wouldn't be possible without your support.

## 🌟 How to Get Listed Here

Contributors are automatically recognized when they:
- Submit a merged pull request
- Report a bug that leads to a fix
- Suggest a feature that gets implemented
- Improve documentation
- Help with testing and QA
- Assist with community management
- Contribute in any meaningful way

## 🎉 Recognition Levels

### 🥉 Bronze Contributors
- 1-5 meaningful contributions
- Listed in CONTRIBUTORS.md
- Thank you in release notes

### 🥈 Silver Contributors
- 6-15 meaningful contributions
- All Bronze benefits
- Special mention in README
- Priority review on PRs

### 🥇 Gold Contributors
- 16+ meaningful contributions
- All Silver benefits
- Invitation to planning discussions
- Name in project credits

### 💎 Diamond Contributors
- Exceptional long-term contributions
- All Gold benefits
- Core team invitation (by consensus)
- Project governance participation

## 📝 How Attribution Works

We follow the [All Contributors](https://allcontributors.org/) specification:
- Every contribution type is valued equally
- Contributors are recognized in this file
- Contribution types are noted with emoji badges
- Attribution is permanent (even if contributor leaves)
